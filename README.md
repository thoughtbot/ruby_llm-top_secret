# RubyLLM::TopSecret

Redact sensitive information from [RubyLLM](https://rubyllm.com) conversations using [Top Secret](https://github.com/thoughtbot/top_secret).

## Installation

Add this line to your application's Gemfile:

```ruby
gem "ruby_llm-top_secret", github: "thoughtbot/ruby_llm-top_secret", branch: "main"
```

Then run:

```bash
bundle install
```
